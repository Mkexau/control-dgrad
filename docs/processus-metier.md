# Processus métier

## 1. Organisation

Le Bureau de contrôle et recoupement comprend deux divisions.

### Division Recoupement

- Bureau Analyse et Recoupement ;
- Bureau Documentation.

### Division Contrôle

- Bureau Contrôle Sol ;
- Bureau Contrôle Sous-sol ;
- Bureau Recettes judiciaires et de participation ;
- Bureau Contrôle Administratif 1 ;
- Bureau Contrôle Administratif 2 ;
- Bureau Contrôle Administratif 3.

Chaque bureau de contrôle est responsable de plusieurs secteurs d'activité.

Chaque secteur d'activité relève d'un bureau de contrôle compétent.

---

## 2. Recoupement et analyse

Le processus commence par la collecte et l'exploitation des informations relatives aux assujettis.

Le Bureau Analyse et Recoupement reçoit les informations transmises par le Service d'assiette et peut également mener des enquêtes.

Les données peuvent notamment comprendre :

- secteur d'activité ;
- numéro de série ;
- délai de traitement ;
- numéro et date de la note de perception ;
- identité de l'assujetti ;
- acte générateur ;
- article budgétaire ;
- nombre d'actes ;
- montants dus en CDF ou USD.

---

## 3. Analyse

Les bureaux analysent notamment :

- entreprises débitrices ;
- absence de déclaration ;
- absence de note de perception ;
- montants restant dus ;
- manque à gagner ;
- répartition par secteur.

Les analyses permettent de déterminer les secteurs prioritaires.

---

## 4. Demande de contrôle sur place

Le Bureau de contrôle compétent prépare le dossier de demande.

Le dossier comprend notamment :

- état statistique ;
- secteur à contrôler ;
- demande officielle ;
- proposition des agents ;
- chefs d'équipe ;
- agents de terrain ;
- entreprises concernées.

Le Bureau de contrôle peut proposer une organisation en plusieurs équipes.

Chaque équipe peut comprendre :

- un chef d'équipe ;
- plusieurs agents de terrain ;
- une ou plusieurs entreprises à contrôler.

---

## 5. Validation du contrôle sur place

Le dossier suit la chaîne :

Bureau de contrôle compétent

→ Chef de Division Contrôle

→ Directeur des contrôles et recoupement

→ Directeur Général

Le Directeur Général peut :

- approuver ;
- rejeter.

Une décision de rejet doit conserver son motif et son historique.

---

## 6. Génération de l'ordre de mission

Après approbation du Directeur Général, le système génère automatiquement l'ordre de mission.

L'ordre de mission peut être :

- consulté ;
- téléchargé ;
- imprimé ;
- conservé au format numérique.

Il doit notamment identifier :

- la mission ;
- les entreprises concernées ;
- les équipes ;
- les chefs d'équipe ;
- les agents affectés.

---

## 7. Équipes de terrain

Une mission sur place peut être organisée en plusieurs équipes.

Chaque équipe possède :

- un chef d'équipe ;
- plusieurs agents ;
- une ou plusieurs entreprises à contrôler.

Les entreprises doivent être affectées aux équipes.

Le chef d'équipe dispose d'une interface dédiée lui permettant notamment de consulter sa mission, son équipe et les entreprises qui lui sont affectées.

---

## 8. Contrôle sur place

Le contrôle est effectué auprès de l'entreprise.

Il peut notamment comprendre :

- examen des pièces ;
- vérification des déclarations ;
- comparaison avec les données de l'administration ;
- vérification comptable ;
- contrôle des systèmes informatiques lorsque nécessaire ;
- détermination des irrégularités.

Le chef d'équipe et les agents affectés peuvent saisir les informations du contrôle dans l'application.

---

## 9. Contrôle sur pièces

Le contrôle sur pièces est considéré comme une mission fonctionnelle de contrôle mais possède un workflow spécifique.

Il :

- ne nécessite pas de déplacement ;
- ne nécessite pas d'ordre de mission ;
- est initié par le Bureau de contrôle compétent ;
- est soumis au Chef de section pour approbation.

Le contrôle sur pièces ne nécessite pas d'équipe de terrain.

---

## 10. Demande de contrôle sur pièces

Le Bureau de contrôle compétent prépare une demande de contrôle sur pièces.

La demande précise notamment :

- l'assujetti concerné ;
- le secteur ;
- l'objet du contrôle ;
- les éléments disponibles ;
- le contrôleur ou les contrôleurs concernés lorsque cela est nécessaire ;
- les documents utiles.

La demande est ensuite soumise au Chef de section.

---

## 11. Approbation du contrôle sur pièces

Le Chef de section peut :

- approuver ;
- rejeter.

Une décision de rejet doit conserver :

- le motif ;
- l'identité du décideur ;
- la date ;
- l'historique de la décision.

---

## 12. Autorisation de contrôle sur pièces

Lorsque le Chef de section approuve la demande, le système génère automatiquement une autorisation de contrôle sur pièces.

Cette autorisation peut être :

- consultée ;
- téléchargée ;
- imprimée ;
- conservée au format numérique ;
- jointe au dossier de contrôle.

L'autorisation constitue la matérialisation applicative de l'approbation du Chef de section.

---

## 13. Exécution du contrôle sur pièces

Le contrôle est réalisé depuis les locaux de l'administration.

Les contrôleurs examinent notamment :

- déclarations ;
- actes générateurs ;
- documents justificatifs ;
- autres informations disponibles.

Le contrôleur peut saisir directement les informations du contrôle dans l'application.

---

## 14. Demande de renseignements

Lorsque les informations disponibles sont insuffisantes, une demande de renseignements, justifications ou éclaircissements peut être adressée à l'assujetti.

Le processus actuel indique un délai de vingt jours pour répondre.

Le système doit permettre de suivre :

- la date d'envoi ;
- la date limite ;
- la réponse ;
- le statut ;
- les documents associés.

---

## 15. Taxation d'office

Le processus actuel prévoit une procédure de taxation d'office dans les situations décrites dans le document source.

Les règles détaillées de calcul et les conditions complètes doivent être précisées avant d'implémenter une automatisation complète.

Le système ne doit pas inventer de règle fiscale ou financière non documentée.

---

## 16. Résultat

Deux situations principales sont prévues.

### Chargée

Des irrégularités sont constatées.

Les montants réellement dus et les éventuelles pénalités sont déterminés.

Le dossier peut notamment comprendre :

- redressements ;
- montants dus ;
- pénalités ;
- justificatifs ;
- éléments de recouvrement.

### Déchargée

Aucune irrégularité n'est relevée ou l'écart résulte notamment :

- d'une erreur administrative ;
- d'une erreur matérielle ;
- d'un double emploi ;
- d'une réclamation fondée.

Le motif ou la justification doit être enregistré.

---

## 17. Procès-verbal

À la fin des opérations de contrôle, un procès-verbal est établi.

Il peut être :

- d'accord ;
- de désaccord ;
- de carence.

Le système doit conserver :

- le type de PV ;
- la date ;
- le contenu ;
- les signataires ;
- les validations ou signatures ;
- les documents associés.

---

## 18. Irrégularités et observations

Lorsqu'une irrégularité est constatée, une feuille d'observations est établie et notifiée selon le processus.

La feuille d'observations est donc conditionnelle.

Une mission ou un contrôle sans irrégularité ne doit pas générer automatiquement une feuille d'observations.

---

## 19. Rapport

Le rapport de mission est élaboré à l'issue des contrôles concernés.

Il est transmis conformément à la chaîne prévue.

Le rapport doit pouvoir être associé :

- à la mission ;
- aux contrôles concernés ;
- aux résultats ;
- aux documents justificatifs.

---

## 20. Clôture

La mission est clôturée après traitement des éléments requis.

Avant la clôture, le système doit vérifier que les éléments obligatoires du parcours sont terminés.

Les éléments importants de la mission doivent rester consultables après clôture selon les permissions applicables.

---

## 21. Documents

Les documents produits ou reçus pendant le processus peuvent notamment comprendre :

- demande de contrôle ;
- ordre de mission ;
- autorisation de contrôle sur pièces ;
- demandes de renseignements ;
- pièces justificatives ;
- procès-verbal ;
- feuille d'observations ;
- rapport ;
- documents de redressement ou de recouvrement.

Les documents doivent être conservés et associés à leur objet métier.

---

## 22. Traçabilité

Les décisions importantes doivent être historisées.

Le système doit notamment conserver :

- auteur ;
- date ;
- action ;
- ancienne valeur lorsque pertinente ;
- nouvelle valeur lorsque pertinente ;
- motif lorsque nécessaire.

Les décisions d'approbation et de rejet doivent être traçables.

---

## 23. Deux parcours principaux

### Contrôle sur place

Bureau de contrôle

→ Chef de Division Contrôle

→ Directeur des contrôles et recoupement

→ Directeur Général

→ Approbation

→ Génération de l'ordre de mission

→ Constitution des équipes

→ Contrôle

→ Résultat

→ PV

→ Observations si irrégularités

→ Rapport

→ Clôture

### Contrôle sur pièces

Bureau de contrôle

→ Demande de contrôle

→ Chef de section

→ Approbation

→ Génération de l'autorisation

→ Contrôle sur pièces

→ Résultat

→ PV

→ Observations si irrégularités

→ Rapport

→ Clôture
